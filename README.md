# Once Upon a Brew

A responsive landing page for a Japanese-inspired matcha tea room, built with React, TypeScript, and CSS.

This is a rebuild of one of my earlier HTML/CSS projects. I wanted to keep the original design while improving the code structure, responsiveness, and maintainability.

The site uses reusable React components, mobile-first styling, CSS Grid and Flexbox, and fluid typography. The rebuild involved reworking the original layouts to behave more consistently across different screen sizes.

**Tech stack:** React · TypeScript · Vite · CSS

The site also includes section navigation, a back-to-top button, an embedded OpenStreetMap map, and a demo contact form with client-side validation.
